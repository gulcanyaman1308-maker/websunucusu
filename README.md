# websunucusu# Java Socket HTTP Server - OOP & SOLID Ödevi

Bu proje, Kırklareli Üniversitesi Yazılım Mühendisliği **Nesneye Yönelik Programlama** dersi kapsamında geliştirilmiştir. Herhangi bir 3. parti kütüphane (Spring Boot, Tomcat vb.) kullanılmadan, **saf Java** ve soket programlama ile sıfırdan bir HTTP web sunucusu yazılmıştır.

## 🚀 Proje Özellikleri
- **Saf Java Soket Mimarisi:** `java.net.ServerSocket` ve `Socket` sınıfları kullanılarak manuel HTTP protokolü yönetimi.
- **Port:** Sunucu **1989** portu üzerinden çalışmaktadır.
- **OOP & SOLID Uyumluluğu:** Tek sorumluluk (Single Responsibility) ve modülerlik prensiplerine uygun olarak sınıflara ayrılmıştır.
- **Dinamik HTML Yanıtı:** İsteğe bağlı olarak `<h1>` etiketinde Ad Soyad, `<h2>` etiketinde Öğrenci No[cite: 1] ve şık kişiselleştirilmiş mor/neon tonlarında biyografi alanı sunar.
